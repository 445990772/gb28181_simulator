# GB28181设备模拟器 - Web界面启动说明

## 📋 前置要求

### Python版本
- Python 3.6+
- 已安装项目依赖（见下方安装步骤）

### Java版本
- JDK 11 或更高版本
- Maven 3.6 或更高版本

### 通用要求
- FFmpeg（需要系统安装并配置到PATH）
- 浏览器（Chrome、Firefox、Edge等现代浏览器）

---

## 🐍 Python版本启动步骤

### 1. 安装依赖

```bash
cd python
pip install -r requirements.txt
```

### 2. 启动后端API服务

```bash
cd web
python3 api_python.py
```

或者：

```bash
# 从项目根目录
python3 web/api_python.py
```

### 3. 访问Web界面

启动成功后，在浏览器中打开：
```
http://localhost:5000
```

---

## ☕ Java版本启动步骤

### 1. 编译项目

```bash
cd java
mvn clean package
```

编译完成后，会在 `target` 目录下生成 `simulator-1.0.0-jar-with-dependencies.jar`

### 2. 启动后端API服务

```bash
cd java
java -cp target/simulator-1.0.0-jar-with-dependencies.jar \
     com.gb28181.simulator.web.ApiServer
```

或者指定端口（默认8080）：

```bash
java -cp target/simulator-1.0.0-jar-with-dependencies.jar \
     com.gb28181.simulator.web.ApiServer 8080
```

### 3. 访问Web界面

启动成功后，在浏览器中打开：
```
http://localhost:8080
```

## 🚀 快速启动（推荐）

### Python版本一键启动脚本

创建 `start_python.sh`（Linux/macOS）或 `start_python.bat`（Windows）：

**Linux/macOS (start_python.sh):**
```bash
#!/bin/bash
cd "$(dirname "$0")"
cd python
pip install -r requirements.txt
cd ../web
python3 api_python.py
```

**Windows (start_python.bat):**
```batch
@echo off
cd python
pip install -r requirements.txt
cd ..\web
python api_python.py
pause
```

### Java版本一键启动脚本

创建 `start_java.sh`（Linux/macOS）或 `start_java.bat`（Windows）：

**Linux/macOS (start_java.sh):**
```bash
#!/bin/bash
cd "$(dirname "$0")"
cd java
mvn clean package
java -cp target/simulator-1.0.0-jar-with-dependencies.jar \
     com.gb28181.simulator.web.ApiServer
```

**Windows (start_java.bat):**
```batch
@echo off
cd java
call mvn clean package
java -cp target/simulator-1.0.0-jar-with-dependencies.jar com.gb28181.simulator.web.ApiServer
pause
```

## 📝 使用流程

1. **启动后端服务**
   - 选择Python或Java版本之一启动
   - 等待看到 "API服务地址" 和 "Web界面地址" 的提示

2. **打开Web界面**
   - 在浏览器中访问显示的地址（默认Python: 5000，Java: 8080）

3. **检查连接**
   - 在Web界面顶部选择对应的后端类型
   - 点击"检查后端连接"按钮，确认连接成功

4. **配置参数**
   - 填写GB28181平台服务器IP和端口
   - 设置设备密码、设备数量、通道数等参数

5. **启动模拟器**
   - 点击"启动模拟器"按钮
   - 等待设备注册成功

6. **查看监控**
   - 监控数据区会显示每个设备的实时数据包大小图表
   - 数据收发区会显示SIP消息的收发记录

## ⚠️ 常见问题

### 1. 端口被占用

**错误信息：** `Address already in use` 或 `端口已被占用`

**解决方法：**
- Python版本：修改 `api_python.py` 中的端口号（默认5000）
- Java版本：启动时指定其他端口，如：`ApiServer 8081`

### 2. 无法连接到后端

**检查项：**
- 确认后端服务已启动
- 确认浏览器访问的地址和端口正确
- 检查防火墙设置
- 查看后端服务的控制台输出是否有错误

### 3. 依赖安装失败

**Python版本：**
```bash
# 使用国内镜像源
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

**Java版本：**
```bash
# 使用国内镜像源（需要配置Maven settings.xml）
mvn clean package
```

### 4. FFmpeg未找到

**错误信息：** `ffmpeg: command not found`

**解决方法：**
- Windows: 下载FFmpeg并添加到系统PATH
- Linux: `sudo apt-get install ffmpeg` 或 `sudo yum install ffmpeg`
- macOS: `brew install ffmpeg`

### 5. 找不到mp4文件

**错误信息：** `未找到可用的本地MP4文件`

**解决方法：**
- Python版本：将mp4文件放到 `python/resources/` 目录
- Java版本：将mp4文件放到 `java/src/main/resources/` 目录

## 🔧 高级配置

### 修改API端口

**Python版本：**
编辑 `web/api_python.py`，修改最后一行：
```python
app.run(host='0.0.0.0', port=5000, debug=False, threaded=True)
```

**Java版本：**
启动时指定端口：
```bash
java -cp target/simulator-1.0.0-jar-with-dependencies.jar \
     com.gb28181.simulator.web.ApiServer 8080
```

### 允许外部访问

默认配置允许外部访问（`host='0.0.0.0'`），如果需要限制只能本地访问：

**Python版本：**
```python
app.run(host='127.0.0.1', port=5000, debug=False, threaded=True)
```

**Java版本：**
需要修改代码中的 `InetSocketAddress` 配置
